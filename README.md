## The entry

> My boss says we're a family here, so I asked for a raise and got grounded until Q3.

83 characters, one line. The joke turns the boss's favourite line —
"we're a family here" — into family discipline: ask for a raise, get
grounded. "Until Q3" lands the punchline in office language.

## How it works

`main.ts` validates the line (one line, 1–200 characters, not only
whitespace), writes it to `/output/entry.txt`, then reads it back to
confirm what landed on disk matches exactly.

Run it with:

```sh
node main.ts
```
